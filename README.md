# 🌶️ 마라자로 맵 (MalaJaro Map)

> 🔗 **라이브 사이트: <https://spaltino.github.io/malajaro-map/>**

중국 주요 도시(상하이·닝보·칭다오)의 **마운자로(穆峰达) 처방 병원·플랜B 약국**, 공항 동선, 세관·보관 가이드를 한 화면에 정리한 인터랙티브 웹 지도 시안입니다.

## 구성

- `index.html` — 단일 파일. 별도 빌드 없이 브라우저에서 바로 열립니다.
- 외부 의존성: Leaflet 1.9.4 CSS/JS(unpkg CDN), OpenStreetMap 타일. 그 외 라이브러리·폰트 CDN 없음.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 도시 탭 | `전체` / `상하이 (浦东)` / `닝보` / `칭다오` — 전체 뷰에서는 도시 묶음 핀으로 표시되고, 핀을 누르면 해당 도시로 이동합니다. |
| 상태 배지 | `전화 확인됨`(초록) · `확인 예정`(주황) · `후기 참고`(파랑) · `플랜B 약국`(보라) — 사실과 추정을 구분합니다. |
| 병원 카드 | 진찰료·재고·공항 동선·세관 서류·항공 참고를 카드에서 바로 확인. 카드를 누르면 지도가 이동하고 팝업이 열립니다. |
| 확인된 곳만 | 전화로 확인이 끝난 곳만 남기는 필터. |
| 원정 손익 계산기 | 항공권 + 진찰료 + 약가(펜 수)를 합산해 총 예상 지출과 한국 대비 절약액을 즉시 계산. 도시·펜 수·약가·환율·한국 기준가 모두 수정 가능. |
| 세관·준비물 가이드 | 2026-11-12 시행 반입 기준(6병/3펜·12회분), 필수 지참 서류, NMPA 처방 기준, 보관·기내 반입 팁, 플랜B 약국 루트. |

## 배포 (GitHub Pages)

- 저장소 루트에 `index.html`·`README.md`를 올린 구성입니다.
- 설정: `Settings → Pages → Deploy from a branch → Branch: main / folder: / (root)`
- 배포 후 1~2분 뒤 <https://spaltino.github.io/malajaro-map/> 에서 열립니다. (2026-11-16 배포 완료)

## 데이터 기준

- 최종 확인일: **2026-11-16**
- 좌표는 WGS84, 지도 타일은 OpenStreetMap.
- 진찰료·약가·환율은 참고값이며, 실제 금액·재고·처방 한도는 방문 당일 병원 판단에 따라 달라집니다.
- 닝보 3곳은 11/17 오전 외국인 처방·재고 전화 확인 예정입니다.
