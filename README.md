# 🌶️ 마라자로 맵 (MalaJaro Map)

> 🔗 **라이브 사이트: <https://spaltino.github.io/malajaro-map/>**

중국 **9개 도시 20곳**(병원 18 · 플랜B 약국 2)의 마운자로(**穆峰达**) 처방 정보를 한 페이지에 정리한 인터랙티브 지도입니다. 인천·김포·부산·제주 출발 항공권 참고가, **공항→병원 실제 지하철 노선**, 세관 한도, **택시기사용 중국어 주소 플래시카드**, 진료실 회화, **한국·중국·일본 3국 가격 비교**, 출국 전 체크리스트, 준비물(쿠팡 파트너스)까지 포함합니다.

## 구성

- `index.html` — 단일 파일. 별도 빌드 없이 브라우저에서 바로 열립니다.
- 외부 의존성: Leaflet 1.9.4 CSS/JS(unpkg CDN), OpenStreetMap 타일. 그 외 라이브러리·폰트 CDN 없음.
- Leaflet/CDN이 막히면 지도 자리에 안내 문구가 뜨고, **카드·필터·계산기는 그대로 동작**합니다(try/catch 폴백).

## 쿠팡 파트너스 구조 (수익화)

`index.html` 상단 `COUPANG_PARTNERS_LINKS` 객체 하나만 고치면 됩니다.

```js
var COUPANG_PARTNERS_LINKS = {
  searchBase: "https://www.coupang.com/np/search?q=",
  coolerPouch:  { q: "인슐린 보냉 파우치 아이스팩", url: "" },
  needles32g:   { q: "인슐린 펜니들 32G 4mm", url: "" },
  swabBin:      { q: "알코올 스왑 휴대용 주사침 폐기통", url: "" },
  chinaEsim:    { q: "중국 eSIM 데이터 무제한 VPN", url: "" },
  adapterPower: { q: "해외 멀티어댑터 중국 고속 보조배터리", url: "" }
};
```

- 각 항목의 **`url`이 비어 있으면** `searchBase + 검색어`로 연결됩니다(현재 상태 = 쿠팡 정식 검색 URL, 가짜 제휴 링크 없음).
- 대표님의 실제 **`link.coupang.com/...` 단축 URL**이 생기면 해당 항목 `url`에 넣기만 하면 즉시 수익화 링크로 바뀝니다.
- 링크에는 `rel="sponsored nofollow"`, `target="_blank"`가 붙어 있고, 섹션 하단에 공정위 문구(파트너스 고지)가 들어 있습니다.

## 데이터 기준

- 최종 확인일: **2026-11-16**
- 좌표는 WGS84(지도 조회값), 지도 타일은 OpenStreetMap.
- 병원 주소·최근접 역·공항 노선은 **병원 공식 안내·역 안내·현지 지도**로 확인한 값만 수록했고, 확인되지 않은 구간은 "현지 앱 확인"으로 표시했습니다.
- 진찰료·약가·환율·항공권은 참고값이며, 실제 금액·재고·처방 한도는 방문 당일 병원 판단에 따라 달라집니다.
- 닝보 3곳은 11/17 오전 외국인 처방·재고 전화 확인 예정입니다.
- 베이징·광저우·선전·항저우·선양·다롄 10곳은 국제진료부·3급 갑등이라는 사실만 확인된 단계로, 외국인 마운자로 처방 사례는 아직 확인되지 않았습니다(`공식 정보(미확인)` 배지).

> 참고용 정보입니다. 의료·법적 판단의 근거로 사용하지 마세요.
