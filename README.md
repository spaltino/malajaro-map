# 🌶️ 마라자로 맵 (MalaJaro Map)

> 🔗 **라이브 사이트: <https://spaltino.github.io/malajaro-map/>**

중국 **9개 도시**의 **마운자로(穆峰达) 처방 병원·플랜B 약국 20곳**, 인천·김포·부산·제주 **출발 공항별 왕복 항공권 참고가**, 공항 동선, 용량별 약가, 세관·보관 가이드를 한 화면에 정리한 인터랙티브 웹 지도입니다.

## 구성

- `index.html` — 단일 파일. 별도 빌드 없이 브라우저에서 바로 열립니다.
- 외부 의존성: Leaflet 1.9.4 CSS/JS(unpkg CDN), OpenStreetMap 타일. 그 외 라이브러리·폰트 CDN 없음.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 도시 탭 | `전체` / `상하이` / `닝보` / `칭다오` / `베이징` / `광저우·선전` / `항저우` / `선양·다롄`. 전체 뷰에서는 도시 묶음 핀으로 표시되고, 핀을 누르면 해당 도시로 이동합니다. |
| 확인 수준 배지 | `전화 확인됨`(초록) · `확인 예정`(주황) · `후기 참고`(파랑) · `공식 정보(미확인)`(회색) · `플랜B 약국`(보라) — 확인 수준을 엄격히 구분합니다. |
| 병원 카드 | 진찰료·재고·처방 한도·공항 동선·항공 참고가를 카드에서 바로 확인. 카드를 누르면 지도가 이동하고 팝업이 열립니다. |
| 전화 확인된 곳만 | 전화로 확인이 끝난 곳만 남기는 필터. |
| 원정 손익 계산기 | **출발 공항(인천·김포·부산·제주)** 과 **도착 도시**를 고르면 왕복 항공권 참고가가 자동 입력되고, **용량(2.5 / 5 / 7.5 / 10mg)** 을 고르면 중국 공식 약가와 한국 기준가가 함께 바뀝니다. 항공권·진찰료·약가(펜 수)를 합산해 총 예상 지출과 한국 대비 절약액을 즉시 계산하며, 모든 값은 직접 수정할 수 있습니다. |
| 세관·준비물 가이드 | 반입 기준(6병 / 3개월분 3펜·12회분), 필수 지참 서류, NMPA 처방 기준, 보관·기내 반입, **용량별 약가표**, 플랜B 약국·징동(JD) 비대면 루트, 도시별 확인 진행 상황. |

## 배포 (GitHub Pages)

- 저장소 루트에 `index.html`·`README.md`를 올린 구성입니다.
- 설정: `Settings → Pages → Deploy from a branch → Branch: main / folder: / (root)`
- 배포 후 1~2분 뒤 <https://spaltino.github.io/malajaro-map/> 에서 열립니다. (2026-11-16 1차 배포, 같은 날 전국 확장판 반영)

## 데이터 기준

- 최종 확인일: **2026-11-16**
- 좌표는 WGS84(Google Maps 조회값), 지도 타일은 OpenStreetMap.
- 공항→병원 택시 소요 시간은 2026-11-16 지도 길찾기 조회값입니다. 지하철 노선은 현지 앱(Amap·百度地圖)으로 다시 확인하세요.
- 진찰료·약가·환율·항공권은 참고값이며, 실제 금액·재고·처방 한도는 방문 당일 병원 판단에 따라 달라집니다.
- 닝보 3곳은 11/17 오전 외국인 처방·재고 전화 확인 예정입니다.
- 베이징·광저우·선전·항저우·선양·다롄 9곳은 국제진료부·3급 갑등이라는 사실만 확인된 단계로, 외국인 마운자로 처방 사례는 아직 확인되지 않았습니다(`공식 정보(미확인)` 배지).

> 참고용 정보입니다. 의료·법적 판단의 근거로 사용하지 마세요.
